# Stajyer Takip Sistemi

ASP.NET Core Web API ile geliştirilen, stajyer bilgilerinin takip ve yönetimini amaçlayan bir backend projesidir.

## Kullanılan Teknolojiler
- ASP.NET Core Web API
- .NET 10
- Entity Framework Core
- PostgreSQL
- JWT Authentication
- BCrypt
- Swagger / OpenAPI

## Mimari / Kullanılan Yapılar
- Controller - Service - Repository yapısı
- Generic Repository
- Unit of Work
- Dependency Injection
- DTO kullanımı
- Rol bazlı yetkilendirme

## Şu Ana Kadar Yapılanlar
- Kullanıcı girişi
- BCrypt ile şifre doğrulama
- JWT token üretimi
- Admin / Mentor / Yönetici rollerine göre yetkilendirme
- Stajyer ekleme
- Stajyer listeleme
- Departman ve mentor bilgilerinin ilişkili olarak getirilmesi
- Swagger üzerinden API testleri

## Proje Durumu
Projenin geliştirilmesine devam edilmektedir.
